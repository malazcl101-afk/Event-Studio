Pick an accent color and save as many named custom themes as you need. Restore appearance defaults whenever you like. Appearance changes persist after reopening.

Back up and move your data

  1. Go to Customize & backup → Download backup. Save the JSON file in a safe place.
  2. On another browser or device, open the same app files and choose Restore backup.
  3. Confirm replacement of that browser’s records. Your backed-up events will appear there.
Data stays on this device. There is no automatic cross-device sync. Clearing browser data or switching browser profiles may erase local records. Make regular backups, particularly before changing devices. A currency change only relabels values; it does not convert money.

Offline and home screen

The downloaded files open locally without internet. To add an installable browser app to a home screen, the files need to be hosted on HTTPS first, for example on your own GitHub Pages site. On iPhone/iPad use Safari’s Share → Add to Home Screen; on Android use your browser menu → Install app or Add to Home screen. Browser availability varies. A local file:// copy is not a shareable URL or an automatic sync service.

Practical tips

  • Blank workspace? Create an event, then select it in the header. Event-specific lists start empty for the customer product.
  • Different device shows no data? Export from the original device and restore on the new one.
  • Restore fails? Choose an unmodified JSON backup from this planner, under 25 MB.
  • Download did not start? Check browser download permission and available disk space.
  • Installed app unavailable? Use the unzipped local file or host the full folder on HTTPS, then retry the browser install menu.
